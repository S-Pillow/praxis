# **22. Bottom Line and Short Form**

The AIPF is a neutral AI-first SDLC written primarily for AI systems operating under human governance. It preserves bounded and attenuated authorization, explicit assumptions, instruction/state provenance, risk disposition, governing intent, source or platform durability, runtime/artifact protection, truthful and provenance-aware evidence, deterministic routing, direct single-agent execution, and human-mediated two-agent continuity.

It should not become bureaucracy for harmless work. Execute the maximum coherent work that can safely share one authorization boundary, with the objective defined at the largest meaningful outcome rather than an arbitrary implementation step. Perform only discovery, verification, recovery proof, review, and evidence collection that can change a current decision or required claim. Reuse valid baselines, risks, limitations, and evidence by impact. The default unit is one meaningful objective; eligible separate low-risk objectives may be batched when they share authority, risk, execution, durability, rollback, and evidence boundaries and remain independently attributable.

Short form. Select the application baseline and reuse valid prior discovery/evidence; route through Section 8; choose Compact or Managed treatment under Section 9.2 and add the urgent-corrective overlay when Section 9.1 requires it; read current canonical state; define one meaningful objective at the maximum safe coherent boundary; apply the Decision-changing work test before adding discovery/verification/review; and establish one bounded authorization unit. If a separate Builder exists: create the T1, retain the Prompt-Agent Derivation Record, transport only the operationally complete Builder Payload or an allowed stable-baseline reference plus delta, have the Builder execute only that payload and return the matching handoff, then reconcile executor-reported assertions against ground state and decision-relevant evidence before the next action. If no separate Builder exists: record the same bounded objective, authority, targets, constraints, acceptance, evidence purpose/observer/feasibility, durability, and stop controls before mutation; execute directly; reconcile result and applicable durability/closure state before new work; derivation partition, transport, and handoff are N/A. In either branch, apply Section 5 Execution result assessment; capability does not equal authorization; AIPF controls do not silently become product requirements; stops are scoped to their actual blast radius; and provenance establishes origin rather than permission.
