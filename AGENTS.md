# AIPF Specialist Suite — agent guidance

This repository contains the optional UI/UX Specialist and its 5,500-entry, read-only design catalog.

- For a material user-facing UI build, improvement, critique, or audit task **in this repository**, use the discoverable `.agents/skills/aipf-ui-ux/SKILL.md` skill. Its short loader points to the single authoritative specialist file at `skills/aipf-ui-ux/SKILL.md`.
- The coding agent, not the user, performs any relevant catalog lookup using `scripts/recommend_design.py` when the repository and Python are available. No Design Index, local server, prompt copying, or manual Python command is required.
- Treat retrieved references as suggestions, never design approval, asset-copying permission, or proof of visual quality. Preserve project-specific rules, existing behavior, approved brand tokens, and applicable AIPF v8.10.1 authority.
- For non-UI work or trivial text edits, do not invoke catalog retrieval without a concrete benefit.

This file is project-scoped guidance, not a substitute for the AIPF standard or a global skill installation.
