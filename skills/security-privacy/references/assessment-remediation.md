# Assessment and remediation

Advisory decisions; examples use dummy inputs and require actual authorization and safe observation. No blanket requirements.

## SD33

**Decision:** Scope, coverage and evidence plan

**Context / use when:** Requested critique, assessment or remediation.

**Alternatives and tradeoffs:** Focused source review by default; broaden only if authorized and decision-relevant. File listing not coverage.

**Constraints / unsuitable conditions:** Record exact revision/config, principal/resource, authorized actions, reviewed/unreviewed surfaces, observer, exclusions and unknowns. No live probe/untrusted execution by implication.

**Verification / revisit:** Trace dummy endpoint actual guard and source lines; list excluded alternate paths/runtime assumptions. No coverage percentage without denominator. Revisit when source, threat, data flow, environment or authorization materially changes.

**Provenance and limits:** SR-06; PS-02; original Praxis synthesis, reference-only. See [source register](../SOURCES.md). Qualify exact version/clauses before decision-sensitive use; no claim of completed verification.

## SD34

**Decision:** Finding classification and refutation

**Context / use when:** Source trace, scanner warning or suspected control failure.

**Alternatives and tradeoffs:** Confirmed for sufficiently established concrete failure; needs validation for plausible lead; rejected for refuted concern; hardening for optional improvement.

**Constraints / unsuitable conditions:** Retain ID, actor/resource, expected control, exact trace, observer, counterevidence, bounded impact, unknown/recheck. AIPF lifecycle is separate. No unsupported severity.

**Verification / revisit:** Synthetic missing ownership guard, unknown alternate path, parameterized path refuting lead and optional defense. Reconcile duplicate root cause and preserve uncertainty. Revisit when source, threat, data flow, environment or authorization materially changes.

**Provenance and limits:** SR-06; PS-01 V8/V15; original Praxis synthesis, reference-only. See [source register](../SOURCES.md). Qualify exact version/clauses before decision-sensitive use; no claim of completed verification.

## SD35

**Decision:** Remediation and security regression

**Context / use when:** Confirmed defect or authorized hardening.

**Alternatives and tradeoffs:** Prefer specific guard or bounded config/patch; retain effective current control where sufficient. Avoid opportunistic refactor.

**Constraints / unsuitable conditions:** State intended behavior, exact negative case, allowed delta, recovery, evidence and residual risk. Preserve original/corrected identity; actual independent check when required.

**Verification / revisit:** Owner succeeds, forbidden actor denied without side effect, unaffected behavior preserved. Unavailable required observation stays pending, not corrected acceptance. Revisit when source, threat, data flow, environment or authorization materially changes.

**Provenance and limits:** SR-05; SR-06; PS-03; original Praxis synthesis, reference-only. See [source register](../SOURCES.md). Qualify exact version/clauses before decision-sensitive use; no claim of completed verification.

## SD36

**Decision:** Responsible disclosure and residual risk

**Context / use when:** Unresolved finding, disclosure or material acceptance.

**Alternatives and tradeoffs:** Private owner-approved channel, minimized redacted evidence; track risk owner/revisit. No public disclosure or certification by default.

**Constraints / unsuitable conditions:** Separate impact, uncertainty, scope and mitigation; never accept risk for owner or provide legal determination. Name missing observation and authorized observer.

**Verification / revisit:** Synthetic report contains no secret/private markers and separates dispositions. Verify intended recipient and scope before authorized transmission. Finding count not assurance. Revisit when source, threat, data flow, environment or authorization materially changes.

**Provenance and limits:** PS-03; PS-04; SR-06; original Praxis synthesis, reference-only. See [source register](../SOURCES.md). Qualify exact version/clauses before decision-sensitive use; no claim of completed verification.
