# PRAXIS-DEC-002 — Builder Context Independence

Status: Owner approved in conversation, 2026-11-24. Supersedes the earlier exclusive-access interpretation and clarifies the v0.1 shared-context language. Applies to Praxis, not standalone AIPF.

Praxis must support Builder Agents with no access to Praxis, AIPF, specialist instructions, catalogs or the project PRD. The Prompt Agent derives and transports an operationally complete authorized Builder Payload. Include all necessary governing values, requirements and selected expertise; refer only to confirmed accessible implementation inputs and stable baselines as allowed by Chapter 21. The Builder does not depend on governing-resource access and does not derive subsequent authorization. Optional access is permitted and confers no additional authority. This is a portability contract, not an access-control mandate. Direct single-agent execution remains supported without artificial handoff. No runtime infrastructure, forced access isolation or host-specific plugin dependency is required.

Verify with a meaningful independent exercise in which the Builder receives only the payload and authorized implementation context and can execute, verify, report and stop without governing resources. Also test optional access and no expanded authority. Do not infer runtime independence solely from static checks or shared-context sessions.
