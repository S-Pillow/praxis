# PRAXIS-DEC-003 — Quality-first prompt synthesis

Status: Owner approved in conversation, 2026-11-24. Applies to Praxis prompt preparation and evaluation. No change to standalone AIPF or canonical T1.

Prioritize product quality, correctness, operational completeness and clarity/precision before token efficiency. Use minimum sufficient instructions, not minimum length. Optimize total execution, clarification, correction and verification cost rather than prompt length alone. Explicitly communicate operational requirements, authorization, protected invariants, evidence and stop conditions. Preserve meaningful implementation discretion within authority. No score can compensate for missing material controls or an unresolved issuance gate. Retain the agreed evaluation rubric and hard gates in TESTING.md; measure actual tokens only with the same named tokenizer/configuration on equivalent payloads. No routine extra scoring ceremony required.
